# Compliance framework sources

All mappings in this directory reference **public standard documents**. Only
control identifiers are stored here — never copyrighted control text.

| Framework                     | Version     | Source                                                                                     |
|-------------------------------|-------------|--------------------------------------------------------------------------------------------|
| NIST SP 800-53                | Rev 5       | https://csrc.nist.gov/publications/detail/sp/800-53/rev-5/final                            |
| CIS Controls                  | v8          | https://www.cisecurity.org/controls/v8                                                     |
| CIS Benchmarks                | current     | https://www.cisecurity.org/cis-benchmarks                                                  |
| PCI DSS                       | 4.0         | https://www.pcisecuritystandards.org/                                                      |
| ISO/IEC 27001 Annex A         | 2022        | https://www.iso.org/standard/27001                                                         |
| OWASP ASVS                    | v4.0.3      | https://owasp.org/www-project-application-security-verification-standard/                  |
| CISA Known Exploited Vulns    | live        | https://www.cisa.gov/known-exploited-vulnerabilities-catalog                               |
| FIRST EPSS                    | live        | https://www.first.org/epss/                                                                |
| NVD CVE database              | live        | https://nvd.nist.gov/                                                                      |

## Attribution policy

- Control **IDs** (e.g. "SC-8", "6.3.3") are factual references and not subject
  to copyright — they can be safely used.
- Control **text and prose descriptions** belong to the respective standards
  bodies and must not be reproduced here. The `rationale` field must paraphrase
  in original words.
- ISO 27001 Annex A text is copyrighted; only the control IDs (e.g. "A.8.24")
  are used.
